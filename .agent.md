# Agent Configuration - Padrões CQRS

## Instruções para Agentes de IA (GitHub Copilot, Cursor, Claude, etc)

Este arquivo contém instruções estruturadas para que agentes de IA implementem corretamente o padrão CQRS no projeto Tilt.

---

## 🎯 Objetivo Principal

Garantir que **100% dos Command Handlers e Query Handlers** sigam o padrão do projeto:
- Use `ICommandHandler<TCommand, TResponse>` ou `IQueryHandler<TQuery, TResponse>`
- Nunca use MediatR
- Sempre retorne `Task<Result<TResponse>>`

---

## 📋 Regras Críticas

### Regra 1: Proibição Absoluta de MediatR
```
IF agente sugere MediatR → REJEITAR
IF agente usa "using MediatR" → ERRO
IF agente implementa IRequestHandler → ERRO
```

**Ação:** Sempre corrigir para `ICommandHandler<>` ou `IQueryHandler<>`

### Regra 2: Interface Obrigatória
```
IF handler não implementa ICommandHandler/IQueryHandler → ERRO
IF handler cria interface específica → ERRO
IF handler usa outro padrão → ERRO
```

**Ação:** Implementar exatamente: `public class XxxHandler : ICommandHandler<XxxCommand, XxxResponse>`

### Regra 3: Assinatura de Método
```
Handler Command: async Task<Result<TResponse>> Handle(TCommand request, CancellationToken cancellationToken)
Handler Query: async Task<Result<TResponse>> Handle(TQuery request, CancellationToken cancellationToken)
```

**Ação:** Rejeitar qualquer assinatura diferente

### Regra 4: Tratamento de Erros
```
IF exception é lançada → ERRO
IF retorna null → ERRO
IF retorna valor sem Result<> → ERRO
```

**Ação:** Sempre capturar e retornar `Result.Fail()`

---

## 🔍 Checklist de Validação

Antes de gerar código, o agente deve validar:

```
VALIDAÇÃO DE COMANDO/QUERY:
- [ ] Nome segue padrão [Ação][Entidade]Command/Query
- [ ] Localizado em pasta correta
- [ ] Herda de ICommand<TResponse> ou IQuery<TResponse>

VALIDAÇÃO DE HANDLER:
- [ ] Nome segue padrão [Ação][Entidade]CommandHandler/QueryHandler
- [ ] Implementa ICommandHandler<> ou IQueryHandler<>
- [ ] Tem método Handle() com assinatura correta
- [ ] Retorna Task<Result<TResponse>>
- [ ] Injeta dependências via construtor

VALIDAÇÃO DE LÓGICA:
- [ ] Command: valida → processa → persiste → retorna
- [ ] Query: busca → valida → retorna
- [ ] Exceções capturadas e convertidas em Result.Fail()
- [ ] Loga com _className
- [ ] Usa CancellationToken em awaits

VALIDAÇÃO DE QUALIDADE:
- [ ] Sem MediatR
- [ ] Sem interfaces específicas
- [ ] Sem service locator
- [ ] Sem exceções lançadas
- [ ] Sem null returns
```

## 📝 Templates Padrão

### Template 1: CommandHandler Básico
```csharp
using Application.Features.[Feature].Contracts;
using Application.Shared.Abstractions;
using Domain.Features.[Feature].Entities;
using Domain.Features.[Feature].Repository;
using FluentResults;
using FluentValidation;
using Microsoft.Extensions.Logging;

namespace Application.Features.[Feature].Commands.[Action];

public class [Action]CommandHandler : ICommandHandler<[Action]Command, [Response]>
{
    private readonly I[Feature]Repository _repository;
    private readonly ILogger<[Action]CommandHandler> _logger;
    private readonly IValidator<[Action]Command> _validator;
    private readonly string _className = nameof([Action]CommandHandler);

    public [Action]CommandHandler(
        ILogger<[Action]CommandHandler> logger,
        IValidator<[Action]Command> validator,
        I[Feature]Repository repository)
    {
        _logger = logger;
        _validator = validator;
        _repository = repository;
    }

    public async Task<Result<[Response]>> Handle([Action]Command request, CancellationToken cancellationToken)
    {
        _logger.LogInformation("[{className}] Executing command", _className);

        try
        {
            var validationResult = await _validator.ValidateAsync(request, cancellationToken);
            if (!validationResult.IsValid)
                return Result.Fail(validationResult.Errors.Select(x => x.ErrorMessage));

            // Implementação
            var entity = [Entity].Create(...);
            var saved = await _repository.SaveAsync(entity, cancellationToken);

            _logger.LogInformation("[{className}] Command executed successfully: {Id}", _className, saved.Id);
            return Result.Ok(([Response])saved);
        }
        catch (Exception ex)
        {
            _logger.LogError("[{className}] Error: {Exception}", _className, ex);
            return Result.Fail(ex.Message);
        }
    }
}
```

### Template 2: QueryHandler Básico
```csharp
using Application.Features.[Feature].Contracts;
using Application.Shared.Abstractions;
using Domain.Features.[Feature].Repository;
using FluentResults;
using Microsoft.Extensions.Logging;

namespace Application.Features.[Feature].Queries.[Action];

public class [Action]QueryHandler : IQueryHandler<[Action]Query, [Response]>
{
    private readonly I[Feature]Repository _repository;
    private readonly ILogger<[Action]QueryHandler> _logger;
    private readonly string _className = nameof([Action]QueryHandler);

    public [Action]QueryHandler(
        ILogger<[Action]QueryHandler> logger,
        I[Feature]Repository repository)
    {
        _logger = logger;
        _repository = repository;
    }

    public async Task<Result<[Response]>> Handle([Action]Query request, CancellationToken cancellationToken)
    {
        try
        {
            var entity = await _repository.GetByIdAsync(request.Id, cancellationToken);
            
            if (entity == null)
                return Result.Fail("Entity not found");

            return Result.Ok(([Response])entity);
        }
        catch (Exception ex)
        {
            _logger.LogError("[{className}] Error: {Exception}", _className, ex);
            return Result.Fail(ex.Message);
        }
    }
}
```

## 🚫 Anti-patterns (Nunca Faça)

```csharp
// ❌ ERRADO 1: Usar MediatR
using MediatR;
public class XxxHandler : IRequestHandler<XxxRequest, XxxResponse>

// ❌ ERRADO 2: Interface específica
public interface ICreateOrderCommandHandler
public class CreateOrderCommandHandler : ICreateOrderCommandHandler

// ❌ ERRADO 3: Lançar exceção
catch (Exception ex)
{
    throw ex;  // ERRADO!
}

// ❌ ERRADO 4: Retornar nulo
if (error) return null;

// ❌ ERRADO 5: Sem Result<>
return entity;  // Deve ser Result.Ok((Response)entity)

// ❌ ERRADO 6: Service Locator
var service = ServiceProvider.GetService<IXxxService>();

// ❌ ERRADO 7: Sem validação em Command
public async Task<Result<XxxResponse>> Handle(XxxCommand request, ...)
{
    // Direto para lógica sem validar
    // ERRADO!
}
```

## ✅ Padrão Aprovado (Sempre Faça)

```csharp
// ✅ CORRETO 1: Interface genérica
public class CreateOrderCommandHandler : ICommandHandler<CreateOrderCommand, OrderResponse>

// ✅ CORRETO 2: Injeção de dependências
public CreateOrderCommandHandler(
    ILogger<CreateOrderCommandHandler> logger,
    IValidator<CreateOrderCommand> validator,
    IOrderRepository repository)

// ✅ CORRETO 3: Validação em Commands
var validationResult = await _validator.ValidateAsync(request);
if (!validationResult.IsValid)
    return Result.Fail(validationResult.Errors.Select(x => x.ErrorMessage));

// ✅ CORRETO 4: Tratamento de erro
catch (Exception ex)
{
    _logger.LogError("[{className}] Error: {Exception}", _className, ex);
    return Result.Fail(ex.Message);
}

// ✅ CORRETO 5: Retorno com Result<>
return Result.Ok((OrderResponse)savedOrder);

// ✅ CORRETO 6: Logging com className
_logger.LogInformation("[{className}] Action performed", _className);
```

## 🎓 Exemplos Reais do Projeto

### Exemplo 1: Command Handler Real
Arquivo: `/Application/Features/Orders/Commands/Create/CreateOrderCommandHandler.cs`

```csharp
public class CreateOrderCommandHandler : ICommandHandler<CreateOrderCommand, OrderResponse>
{
    private readonly IUnitOfWork _unitOfWork;
    private readonly ILogger<CreateOrderCommandHandler> _logger;
    private readonly IValidator<CreateOrderCommand> _validator;
    private readonly string className = nameof(CreateOrderCommandHandler);

    public CreateOrderCommandHandler(
        ILogger<CreateOrderCommandHandler> logger,
        IValidator<CreateOrderCommand> validator,
        IUnitOfWork unitOfWork)
    {
        _logger = logger;
        _validator = validator;
        _unitOfWork = unitOfWork;
    }

    public async Task<Result<OrderResponse>> Handle(CreateOrderCommand request, CancellationToken cancellationToken)
    {
        _logger.LogInformation("[{className}] Creating an Order {UserId}", className, request.UserId);

        try
        {
            var validationResult = _validator.Validate(request);
            if (!validationResult.IsValid) 
                return Result.Fail(validationResult.Errors.Select(x => x.ErrorMessage));

            var order = Order.Create(null, user, request.RequestedTime, request.Addresses, DateTime.Now);
            var savedOrder = await _unitOfWork.OrderRepository.SaveAsync(order);

            _logger.LogInformation("[{className}] Order Created {savedOrderId}", className, savedOrder.Id);
            return Result.Ok((OrderResponse)savedOrder);
        }
        catch (Exception ex)
        {
            _logger.LogError("[{className}] Error: {request} Error: {ex}", className, request, ex);
            throw;
        }
    }
}
```

1. **Agente recebe solicitação:**
   ```
   "Implemente um CommandHandler para CreateSubscription"
   ```

   - Verifica se não é para usar MediatR
   - Verifica padrão correto `ICommandHandler<>`
   - Verifica pasta correta
   - Verifica nome correto

3. **Agente gera código:**
   - Usa template aprovado
   - Implementa validação
   - Implementa tratamento de erro
   - Adiciona logging

4. **Agente valida gerado:**
   - Checklist completo
   - Sem anti-patterns
   - Pronto para usar
